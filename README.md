# CONTABIL
Crie o projeto CONTABIL neste repositório.

App web de contabilidade para empresas no Brasil (HTML, CSS e JS, backend).

Inclua:
- Dashboard com resumo
- Cadastro de empresas
- Simulador: Simples Nacional, Lucro Presumido e Lucro Real
- Alertas de vencimento (DAS, FGTS, ISS, IRPJ)
- Exportar PDF

Use index.html + pasta assets. Depois configure GitHub Pages na branch main.
